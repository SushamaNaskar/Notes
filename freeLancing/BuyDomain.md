- after that time period we need to renew the rent again. (known as renewals)

# The process of buying
- connect on a call with the client

# Step 1 — Decide the domain

Ask:

What domain name would you like?

Example:

abctax.com
abctax.in
abcconsultants.com

Check availability together.

# Step 2 — Create the registrar account

Have the client create the selected domain platform account.

They'll need:

Name
Email
Password

This account belongs to them.

# Step 3 — Buy the domain

They purchase the domain.

Now the domain belongs to the client.

# Step 4 — Get temporary access
you will need temporary access to configure the DNS and connect the website. Once everything is set up, the customer can change the password if they'd like.

### 1. Option A (recommended)

### 2.Option B

The client shares:

Email
Password

After you're done:

client changes password
you're finished

This is common for freelancers working with small businesses.


# Some important points to remember during buying the domain
1. Always check the renewal cost and Inform client about renewals

When comparing prices, always check the renewal cost, not just the first-year offer. A domain is an ongoing expense, and clients are often surprised when a ₹1 promotion becomes a much higher renewal fee later. It's worth pointing that out so they can make an informed choice.


# 1. What is a domain renewal?

Buying a domain is not a one-time purchase.

Think of it like renting a shop.

You don't buy the shop forever.

You pay every year to keep using it.

For example:
```
abctax.com

Buy today:
₹1,200

Valid until:
30 July 2027

On 30 July 2027 you must renew it.

Renew = Pay again for another year.
```

## If you don't renew
the website stops working
emails stop working
eventually someone else can buy the domain.


# NameCheap
Web Hosting / Website Builder — you don't need this, you're using Vercel/Netlify/GitHub Pages, which are free and better suited for a coded portfolio than a drag-and-drop builder

WordPress Hosting — irrelevant, you're not building a WordPress site
SSL (₹574.19/yr) — as covered earlier, your host will give you this for free automatically. Paying for it here is redundant.

Business Email — nice to have eventually (e.g. you@yourname.dev), but not needed to launch, and often cheaper/free elsewhere (Zoho Mail has a solid free tier, or Cloudflare Email Routing forwards to your existing Gmail for free)
Boost Your Social Media / AI content — unrelated to your goal, skip
VPN — unrelated, skip

Premium DNS (₹467.78) — the free DNS that comes with your domain is fine for a personal portfolio. Premium DNS is for high-traffic sites needing extra speed/redundancy, not something you need at launch.

Rank Higher in Search / SEO tasks — for a portfolio, good project write-ups and clean code matter far more than paid SEO tools
