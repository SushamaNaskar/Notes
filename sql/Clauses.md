In SQL, clauses are the building blocks of a query. Each clause performs a specific task.

# Common SQL Clauses
| Clause          | Purpose                               |
| --------------- | ------------------------------------- |
| `SELECT`        | Chooses the columns to display        |
| `FROM`          | Specifies the table(s) to query       |
| `WHERE`         | Filters rows before grouping          |
| `GROUP BY`      | Groups rows with the same values      |
| `HAVING`        | Filters groups after grouping         |
| `ORDER BY`      | Sorts the result                      |
| `LIMIT` / `TOP` | Restricts the number of rows returned |
| `JOIN`          | Combines data from multiple tables    |
