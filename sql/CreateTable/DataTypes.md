| Data Type                | Stores                      | Example               |
| ------------------------ | --------------------------- | --------------------- |
| `INT`                    | Whole numbers               | 1, 100, -5            |
| `VARCHAR(n)`             | Variable-length text        | 'John', 'Hello'       |
| `CHAR(n)`                | Fixed-length text           | 'A', 'USA'            |
| `DECIMAL(p,s)`           | Exact decimal numbers       | 99.99, 1234.56        |
| `FLOAT`                  | Approximate decimal numbers | 3.14159               |
| `DATE`                   | Date only                   | '2026-06-07'          |
| `TIME`                   | Time only                   | '14:30:00'            |
| `DATETIME` / `TIMESTAMP` | Date and time               | '2026-06-07 14:30:00' |
| `BOOLEAN`                | TRUE/FALSE                  | TRUE, FALSE           |
