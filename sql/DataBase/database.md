# DataBase
A database is a collection of data stored in a format that can be easily accessed, maganed and updated.

# Why do we need data base?
Most application needs a database to store and retrive data

Example:
A shopping website like Amazon will need a database to store data about customers, products and orders.

# DBMS
Database Management System is a software systems used to manage and manipulate data in database.

A DBMS server is an interface between an end-user and a database, allowing user to create,read, update and delete data in database

# Types of database

2. NoSql database
